### 二、开发记录中的关键章节

#### 1. 华宝油气估值公式原理
```
EST = 前一交易日净值 × [1 + (跟踪指数涨跌幅 × 仓位比例)] × 汇率调整系数
```

**关键参数**：
- 仓位：LOF取95%，ETF取100%
- 汇率：使用美元人民币中间价（非实时汇率）
- 跟踪指数：XOP净值（非交易价）

#### 2. 三种EST的定义

| EST类型 | 数据来源 | 核心用途 |
|---------|---------|---------|
| **官方EST** | T日美股收盘数据 + T日汇率 | 验证算法、测算申赎成本 |
| **参考EST** | 官方EST + T+1日汇率 | 套利决策、XOP配对交易 |
| **实时EST** | 参考EST + CL期货实时数据 | CL期货配对交易 |

#### 3. 套利原则
- **折价不申购，溢价不赎回**
- **上涨赚净值，下跌赚溢价**
- **不要怂，就是干！**

## 📖 核心知识点整理

### 一、LOF套利基础

#### 1. 套利类型

| 类型 | 条件 | 操作 | 成本 |
|------|------|------|------|
| **溢价套利** | 场内价格 > 净值 | 申购 → 卖出 | ~1.8%（申购1.5%+卖出0.3%）|
| **折价套利** | 场内价格 < 净值 | 买入 → 赎回 | ~0.8%（买入0.3%+赎回0.5%）|

#### 2. 时间周期

| 基金类型 | 申购到账 | 赎回到账 |
|---------|---------|---------|
| A股LOF | T+2 | T+3 |
| QDII-LOF（华宝油气） | T+2 | T+3 |
| QDII-LOF（165513等） | T+3 | T+4 |

### 二、跨市场套利

#### 1. 华宝油气 + XOP
```
T日：溢价申购华宝油气 + 做空XOP
T+2日：华宝油气到账，卖出平仓XOP
```

#### 2. 嘉实黄金 + GLD
```
T日：折价买入160719 + 做空GLD + 做空USD/CNH（汇率对冲）
T+7日：赎回160719，平仓GLD和外汇
```

### 三、对冲配比计算

#### 1. GLD空头计算
```
GLD敞口(美元) = 160719投资金额(人民币) × 仓位 / 汇率

例：10万元 × 0.96 / 6.98 ≈ $13,754
GLD价格$200 → 做空约70股
```

#### 2. 外汇对冲计算
```
USD/CNH空头金额 = GLD敞口

例：$13,754 / 100,000 = 0.14手
使用10-20倍杠杆，实际占用资金约$700-1400
```

## ⚠️ 风险提示

1. **汇率风险**：QDII基金涉及汇率波动
2. **时差风险**：美股和A股交易时间不同步
3. **流动性风险**：部分LOF成交量小，冲击成本高
4. **政策风险**：QDII额度限制可能导致暂停申购
5. **估值滞后**：官方EST可能有1天滞后

1. **首次操作**：先用小资金（1-2万元）测试完整流程

4. **分散标的**：不要单吊一个LOF品种
